## 실행 방법  
위 다운로드 링크에서 ZIP파일 압축 해제 후 CantAttack.exe파일 실행

---

## 조작법
이동: 방향키

점프: Z (길게 누르면 높이 증가)

회피/대시: C

패링: X

---

## 주요 특징
- 튜토리얼 구역 포함 총 6개의 맵
- 기본 적: Melee_A
- 장애물 4종: Crusher, Saw, BallShooter, Spike
- 기본 패링 기술 2종: 투사체를 되돌려 발사하는 패링, 근접 공격을 패링하여 적에게 스턴 부여
- 간단한 도전 구역(Trial Area)
- 보스전 및 보스 몬스터
- 플레이어 / 세이브/ 로드 / UI / Input / 이벤트 / 게임이벤트 / 포탈 / 카메라 / 오디오 / 부팅 / Loading /대사 / 피격 시스템

---

## 업데이트 예정
- 퀘스트 / 인벤토리 / 아이템 / 지도 / NPC 대화 / 환경설정 / 패링 기술 교체 시스템 추가
- 입력 시스템을 New Input System으로 리팩토링
- 맵 확장 + 보스 패턴 추가
- 패링 기술 확장
    - 패링 방패 모드:
        - 여러 종류의 방패 장착 (3~4개)
        - 숫자키(1~4)로 실시간 교체
        - 패링 시 선택된 방패의 특수 효과 발동 (산탄, 화상, 튕김, 반동 등)
    - 패링 조준 모드:
        - 조준 방식도 장착하고 교체 가능 (3~4개)
        - 조준 방식 예시:
            - 쏜 적에게 자동 조준
            - 방향키 기반 조준 (12시 / 1시 / 3시 / 5시 등)
            - 가장 가까운 적 조준
